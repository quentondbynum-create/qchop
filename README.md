# QChop

Sample slicer by **Headroom Audio**.

Drag in a loop → QChop auto-slices it by transient/onset detection into up to 16 slices → trigger them from the 4×4 RGB pad grid (click or MIDI), tweak pitch/reverse/level per slice, rearrange your flip.

- 16 velocity-sensitive-feel pads, each with its own vivid color
- Spectral-flux onset detection for auto-slicing; drag markers to adjust
- Per-slice pitch (±12 st), reverse, level
- MIDI note triggering (C1–D#2)
- Preset menu with favorites, Headroom Audio branding

Built with JUCE 7.0.12. Mac/Windows builds via GitHub Actions.
